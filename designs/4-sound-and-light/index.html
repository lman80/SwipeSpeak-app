Questions

Is it really free?

Yes. No account, no subscription, no SwipeSpeak server. Cloud dictation and ✨ summaries use your own free Groq key.

Which Macs does it run on?

macOS 14 Sonoma or later, on Apple silicon (M1 or later).

Why does macOS ask me to “Open Anyway”?

SwipeSpeak isn't from the App Store, so the first time you open it macOS blocks it. Go to System Settings › Privacy & Security, scroll down and click Open Anyway. You only do this once.

Do I need an API key?

Only for fast cloud dictation and ✨ summaries: a free key from console.groq.com/keys. Offline dictation and reading aloud need no key.

Does my text leave my Mac?

Reading aloud happens on your Mac. Text is sent only for ✨ summaries (to Groq). Dictation audio goes to Groq in cloud mode, or stays on your Mac in offline mode.

Which voice reads to me?

Your Mac's own Spoken Content voice (the Siri voices), at the speed you've set. Speak Selection must be on in System Settings › Accessibility › Spoken Content; the Setup Guide helps.

Which apps does it work in?

Almost any app where you can type or select text: mail, chat, browsers, documents, notes, code editors and PDFs.
